- 데이터 소스(KRX OPEN API, OpenDART, SEC EDGAR)의 엔드포인트·제공 범위·호출 한도·이용 조건 설명 중 **틀렸거나 바뀐 것**

- **미래 정보 사용(look-ahead)·생존자 편향·과최적화** 위험이 남아 있는 지점

- 한국 시장 특유의 이슈(지주사 할인, 순환출자, 상장 자회사 중복 상장, 테마주 등)에서 놓친 것
