# 실험 기록

> 목적: 과최적화 방지. 유니버스·사업군·지표 정의·이상치·결측·필터·가중치·리밸런싱 규칙은 모두 **전략의 일부**이므로, 바꿀 때마다 여기에 기록한다. (DESIGN 7.4)

## 규칙
1. **기록 없는 설정 변경 금지.** 변경은 `config/strategy_vN.yaml`의 새 버전으로만 한다.
2. 실험은 **개발 구간(2015~2021)** 에서만 한다.
3. **검증 구간(2022~)** 은 전략 버전을 확정한 뒤에만 실행한다. 실행할 때마다 아래 "검증 구간 열람 기록"에 남긴다.
4. 결과가 나쁜 실험도 지우지 않는다. 실험 횟수 자체가 과최적화 위험을 판단하는 정보다.
5. 채택 여부는 사전에 정한 기준으로 판단한다. 기본 기준: 비용 차감 후 IC 평균 개선 **그리고** 최대낙폭 악화 없음.
