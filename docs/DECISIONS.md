## ⏳ 열린 질문

### D-07 화면 배포 방식 — 3단계 전에 결정
| 선택안 | 장점 | 확인할 것 |
|---|---|---|
| A. GitHub Pages | 저장소와 일체 | Private 저장소 Pages의 요금제 조건, 접근 통제 가능 여부 |
| B. Vercel | 계정 이미 연결됨, 접근 보호 기능 | 보호 기능의 요금제 조건 |
| C. 로컬 HTML | 비용 0, 완전 비공개 | 자동성 떨어짐 |

### D-08 수집 실행 시각 — 0단계 실측 중
- 측정 스케줄: 평일 KST 15:40 / 16:40 / 17:40 / 18:40 / 20:40, 다음날 08:10
- 기록: `reports/phase0/timing.csv`
- 1주 측정 후 스케줄을 삭제한다.

### D-14 운용 기준 금액 — 2단계 전에 결정 (사용자 결정 사항)
유동성 한도(주문 금액 ≤ 20일 평균 거래대금의 5%)와 비용 시나리오 계산에 쓸 기준 금액.

| 선택안 | 영향 |
|---|---|
| 소액 (예: 1천만 원) | 유동성 제약 거의 없음 |
| 중액 (예: 1억 원) | 소형주 일부가 제약 받음 |
| 실제 계획 금액 | 가장 현실적 |

### D-20 EBITDA/EV 지표 처리 — 1단계 실측으로 새로 생김 (협의 대상)
1단계 표본 25개사 중 EBITDA/EV 계산 가능 **3개사(12%)**. 감가상각비를 표준 계정 ID로 공시하는 회사가 적기 때문 ([PHASE1_STATUS](PHASE1_STATUS.md)).

| 선택안 | 커버리지 | 장점 | 단점 |
|---|---|---|---|
| A. EBITDA/EV 유지 (계산 가능할 때만) | 12% | 설계 그대로 | 가치 묶음에서 사실상 빠짐, 공시 방식에 따른 편향 |
| B. **EBIT/EV(영업이익/EV)로 교체** | 96% | 같은 "기업가치 대비 이익" 개념, 거의 전 종목 계산 | 감가상각 비중이 큰 업종(장치산업)에 불리 |
| C. 감가상각비를 비표준 계정명·주석까지 확장 수집 후 EBITDA 유지 | 미측정 | 원 설계 의도 유지 | 매핑 작업량 큼, 주석 파싱 필요 |

※ 성과(수익률)를 보지 않은 상태에서 데이터 커버리지만으로 판단하는 변경이므로 과최적화와 무관. 단, 전략 정의 변경이라 기록 후 결정.

### D-21 백테스트 시작 시점 — 1단계 실측으로 새로 생김 (협의 대상)
DART 재무 API는 **2015년 분기·반기 재무를 제공하지 않는다** (2015 사업보고서만, 표본 20/20 확인).

| 시점 | 가능한 것 |
|---|---|
| 2017년 4월~ | 최초 TTM (2016년 연간) → 가치·수익성 지표 |
| 2018년 4월~ | 전년 대비 지표 (F-스코어, 영업이익 증가율) 포함 전체 모델 |

| 선택안 | 개발 구간 | 장점 | 단점 |
|---|---|---|---|
| A. 전체 모델 기준 2018년 4월 시작 | 2018-04 ~ 2021 (약 3.7년) | 단순, 모든 지표 동일 조건 | 개발 구간이 짧음 |
| B. 2017년 4월 시작, 첫 1년은 전년 대비 지표 없이 | 2017-04 ~ 2021 | 구간 1년 연장 | 첫 1년 모델이 다름 → 비교 해석 주의 |

| D. 검증 구간을 줄여 개발 구간 확대 (예: 개발 ~2022, 검증 2023~) | 2018-04 ~ 2022 | 개발 표본 증가 | 검증 구간 짧아짐 |
