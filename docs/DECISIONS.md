## ⏳ 열린 질문

### D-07 화면 배포 방식 — 3단계 전에 결정
| 선택안 | 장점 | 확인할 것 |
|---|---|---|
| A. GitHub Pages | 저장소와 일체 | Private 저장소 Pages의 요금제 조건, 접근 통제 가능 여부 |
| B. Vercel | 계정 이미 연결됨, 접근 보호 기능 | 보호 기능의 요금제 조건 |
| C. 로컬 HTML | 비용 0, 완전 비공개 | 자동성 떨어짐 |

### D-08 수집 실행 시각 — 0단계 실측 중
KRX OPEN API의 당일 데이터 제공 시각을 실측한 뒤 정한다.
- 측정 스케줄: 평일 KST 15:40 / 16:40 / 17:40 / 18:40 / 20:40, 다음날 08:10
- 기록 위치: `reports/phase0/timing.csv`
- 1주 측정 후 스케줄을 삭제한다.

### D-15 코스피 관리종목 식별 소스 — 1단계 중 결정
0단계 확인 결과, KRX 종목기본정보의 소속부 필드에 **코스닥은 관리종목이 표시되지만 코스피는 빈 값**이다.

| 선택안 | 장점 | 단점 |
|---|---|---|
| A. KIND 관리종목 현황 수집 | 공식 공시 채널 | 페이지 구조 변경 위험, 수집 방식 확인 필요 |
| B. DART 공시 검색 (관리종목 지정·해제 공시) | 공식 API, 이력 확보 가능 | 공시 문구 기반 분류 필요 |
| C. 코스피 관리종목 필터 생략 | 단순 | 코스피 부실 종목이 유니버스에 남음 (다른 위험 필터로 일부 보완) |

→ 2차 협의 Q7에서 결정 ([`reviews/round2/`](../reviews/round2/))

### D-16 수정주가 계산 방식 — 1단계 중 결정
KRX는 원 종가만 제공한다. 12-1 모멘텀·백테스트 수익률에 수정주가가 필요하다.

| 선택안 | 장점 | 단점 |
|---|---|---|
| A. 상장주식수 변화 + 가격 불연속으로 분할·병합 자동 감지 | 공식 데이터만 사용 | 유상증자·무상증자 구분이 어려움 |
| B. DART 주요사항보고(분할·병합·증자 결정) 공시로 보정 | 사유가 명확 | 공시 파싱 필요 |
| C. 비공식 소스의 수정주가 사용 | 구현 간단 | 비공식, 재현성·지속성 위험 |

→ 2차 협의 Q8에서 결정

### D-14 운용 기준 금액 — 2단계 전에 결정
유동성 한도(주문 금액 ≤ 20일 평균 거래대금의 5%)와 비용 시나리오 계산에 쓸 기준 금액.

| 선택안 | 영향 |
|---|---|
| 소액 (예: 1천만 원) | 유동성 제약 거의 없음 |
| 중액 (예: 1억 원) | 소형주 일부가 제약 받음 |
| 실제 계획 금액 | 가장 현실적 |
