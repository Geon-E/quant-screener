## 수정주가 (D-16) — 2026-10-25

**방식**: KRX 공식 기준가로 조정계수 산출. 조정계수 = (종가 − 전일대비) ÷ 전일 종가. 기업행위가 없는 날은 정확히 1.

| 결과 | 값 |
|---|---|
| 대상 | 2,870종목, 2025-09 ~ 2026-10 |
| 감지 사건 | 884건 — 주식병합 282 · 분할 21 · 권리락 162 · 인적분할·감자 등 78 · SPAC 기준가 상향 334 · 미세 7 |
| 검산 (KRX 등락률과 정합) | 최대 0.005%p (반올림 수준) — 같은 KRX 필드 기반이라 **독립 검증 아님** |
| **독립 교차검증** (FinanceDataReader 수정주가, 80종목) | 사건 있는 74종목의 누적수익률 상대차이 **중앙값 0.000%** |
| 교차검증 이상치 4건 | 에이프로젠·에이프로젠바이오로직스: DART로 **15:1 감자** 확인 → 우리 값이 맞고 비공식 소스가 감자 미반영. 페이퍼코리아: 5:1 병합, 소폭 차이. 선도전기: 아래 |
| 표본 공시 확인 | 확인 필요 사건 14건 중 7건 DART 확인 (나머지 7건은 SPAC 기준가 상향 — 유니버스 제외 대상) |

**발견 — 기준가 변경 ≠ 기업행위**
- 선도전기(2026-04-29): 주식수 변화 없이 기준가가 3,000원 → 5,000원으로 재설정됐다.
- 이런 경우 조정계수로 적용하면 실제 가격 변동을 지우게 된다.
- 현재 정책: 주식수 역수 관계(분할·병합)나 DART 공시로 확인되지 않은 사건이 13개월 안에 있으면 **그 종목의 모멘텀은 무효**. 잘못된 보정으로 값을 만들지 않는다.
- 2단계 백테스트 수익률 계산에서는 미확인 사건을 **보정하지 않는 것**을 기본으로 하고, 해당 종목에 플래그를 붙인다 (4차 협의 안건).

**설계와의 차이 (투명성)**
- D-16 합의 문구는 "공시 기반 보정"이다. 구현은 **거래소 공식 기준가를 주 소스**로, 공시는 사건 확인용으로 쓴다.
- 근거: 공시 문서 파싱보다 거래소가 실제 적용한 수치가 더 정확하고 재현 가능하다.
- 4차 협의에서 이 차이를 확인받는다.
