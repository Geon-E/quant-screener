# 해외(미국) 확장 가능성 점검 — 4단계 사전 조사

> 작성 2026-10-25. 국내 완료 후 착수 예정 (DESIGN 9단계 계획). 여기서는 "국내와 같은 방식이 무료로 되는가"만 본다.
> 표기: ✅ 출처로 확인 / 🔶 Claude 사전 지식 — CI에서 실측 필요

## 결론

**재무는 국내보다 쉽고, 시세가 병목이다.**
- 재무: SEC EDGAR가 무료·공식·키 없음이다. 공시일(filed)이 값마다 붙어 있어 시점 정합성 복원이 DART보다 쉽다 (🔶).
- 시세: 무료 공식 소스가 없다.
  - 무료 API(Massive, 옛 Polygon)는 분당 5회, 장마감 데이터만 준다. 전 종목 하루치를 1회에 받는 방식(grouped daily)이라 매일 갱신은 가능하다.
  - 다만 백테스트용 과거 기간이 짧다 (🔶 무료는 약 2년).
- 그래서 **현재 시점 스크리너는 무료로 가능**하다. **장기 백테스트는 시세 소스 결정(유료 또는 다른 무료 소스)이 필요**하다.

## 소스별

| 영역 | 소스 | 조건 | 상태 |
|---|---|---|---|
| 재무 (전 종목) | SEC EDGAR `data.sec.gov/api/xbrl/companyfacts/CIK##########.json` | 무료, 키 없음, 초당 10회 이하, User-Agent에 연락처 필수 | ✅ |
| 재무 일괄 | `companyfacts.zip` (매일 갱신되는 전 종목 묶음) | 1회 다운로드로 전 종목 — 호출 한도 걱정 없음 | 🔶 |
| 공시 이력 | `data.sec.gov/submissions/CIK##########.json` (양식·공시일·접수번호) | 무료 | ✅ |
| 시점 정합성 | companyfacts의 각 값에 `filed`(공시일)·`accn`(접수번호)·`form`(10-K/10-Q/정정) | 같은 기간의 여러 버전을 공시일로 구분 → 최초 공시 값 복원 가능 | 🔶 |
| 업종 | submissions의 `sic` 코드 | 국내 KSIC 사업군 표와 같은 방식으로 SIC 사업군 표 작성 | 🔶 |
| 발행주식수 | `dei:EntityCommonStockSharesOutstanding` | 시가총액 = 주식수 × 종가 | 🔶 |
| 시세 (매일) | Massive(옛 Polygon) 무료: 분당 5회, 장마감 데이터, 전날 데이터는 미국 동부 자정 이후 | 전 종목 하루치 1회 호출 → 매일 갱신 가능 | ✅ 호출 한도·시각 |
| 시세 (과거) | 같은 무료 등급 | 과거 기간 제한 (약 2년) | 🔶 |
| 상장폐지 종목 시세 | grouped daily는 그날 거래된 종목 전부 포함 | 받은 기간 안에서는 생존자 편향 없음 | 🔶 |

## 국내 코드와 재사용

| 국내 | 미국 | 재사용 |
|---|---|---|
| DART 재무 → 계정 규칙(account_rules.yaml) | companyfacts의 us-gaap 태그 | 규칙 파일만 새로 (us-gaap 태그는 표준화가 잘 돼 있어 대체 규칙이 적게 필요) |
| TTM·분기 복원 | 10-Q 누적값 → 같은 방식 (미국은 회계연도가 회사마다 달라 기간 처리가 더 필요) | 수정 필요 |
| 점수·화면·백테스트 | 그대로 | 그대로 |
| 수정주가 (KRX 기준가) | 분할·배당 정보로 직접 계산 | 새로 |

## 남은 결정 (착수 시)

1. **시세 소스**: (a) 무료 API로 현재 화면만 (b) 장기 백테스트용 유료 데이터 (c) 다른 무료 소스 조사 — 이용 조건 확인 필수
2. **대상**: 미국 전체 상장(약 6천 종목) vs S&P 500·나스닥 100 등 대형주로 시작
3. **환율**: 원화 기준으로 볼지
4. **회계연도**: 12월 외 결산 비중이 국내보다 커서, 국내처럼 제외하면 표본 손실이 크다 → 회계연도별 TTM 처리 필요
