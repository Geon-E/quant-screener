# v2.0 분석 결과 (재설계 배경)

> 대상: [`legacy/Global_Quant_Platform_v2.0.html`](../legacy/Global_Quant_Platform_v2.0.html) — 파일 업로드 기반 단일 HTML 멀티팩터 스크리너
> 결론: 코드 완성도는 높으나 **자동 수집 불가 구조**이고, 아래 계산상 허점이 있어 재설계 결정 (DECISIONS D-00)

## 잘 된 점 (재사용 대상)
- PER·PBR 대신 역수(E/P·B/P)로 순위 → 적자·자본잠식 자동 최하위
- 동점 평균순위를 쓰는 백분위 엔진, 결측 처리 옵션
- 금액 단위 자동 추정 휴리스틱 (주식수 ÷ 거래량 ≈ 200)
- 지표 정의가 `FACTORS` 한 곳에 모여 확장 쉬움, XSS 이스케이프 일관적
- 디자인 토큰·다크모드·반응형, 표·차트 컴포넌트

## 코드 버그 (참고)
- 매핑 프로필 자동 적용 조건이 `prof && src.mapping.code` → 수동 매핑했던 형식은 매번 매핑창 재표시
- 헤더 서명이 같은 파일은 의미가 달라도 같은 매핑이 확인 없이 적용
- `detectType`: 헤더가 `ttm`으로 시작하는 해외 파일이 DART 재무로 오인되어 국가 KR 고정
- 기본 전략으로 지정된 사용자 전략 삭제 시 `settings.defStrat` 미갱신
- 리밸런싱: 데이터에 없고 평균단가 0인 보유 종목은 매도 금액 0으로 합계 누락
- SheetJS 0.18.5 (조작된 파일 읽기 관련 알려진 취약점) → 최신 버전 권장
- 환율 기본값 1,340원 하드코딩
