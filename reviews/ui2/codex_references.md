# 화면 재설계 레퍼런스 (Codex)

## 지금 화면에서 보이는 문제

1. **찾기 전에 설명과 요약이 화면을 많이 차지합니다.** PC에서는 제목·상태·주의 문구·검색창·사업군 칩·관심 종목 카드가 이어진 뒤에야 종목 목록이 나옵니다. 휴대폰에서는 첫 화면 대부분을 이 영역이 차지해, 바로 종목을 찾으려는 사용자가 목록까지 더 내려가야 합니다.
2. **휴대폰에서 사업군 빠른 선택이 잘린 채 이어집니다.** 칩이 가로로 넘치지만 다음 칩이 일부만 보여, 더 있다는 사실과 이동 방법이 분명하지 않습니다.
3. **PC 목록은 가로 정보량이 많고, 종목 이름보다 지표 열을 훑기 쉽습니다.** 표에 사업군, 위치, 점수 분포, PER·PBR·ROE, 모멘텀, 시총, 비고가 한 줄에 놓여 있습니다. 재설계의 중심인 종목 찾기와 같은 사업군 비교가 첫 시선에서 경쟁합니다.
4. **점수 가설을 설명하는 요소가 여러 곳에 반복됩니다.** 상단 주의 문구, 목록 위 범례, 행의 순위·점수, 상세의 점수·구간 설명이 함께 보입니다. 경고가 필요한 이유는 있지만, 서로 다른 정보를 찾으려면 비슷한 안내를 반복해서 지나야 합니다.
5. **휴대폰 종목 상세가 긴 한 장의 시트로 열립니다.** 캡처에서 회사 설명, 점수 묶음, 사업군 위치, 지표 비교가 세로로 이어집니다. 회계 점검·경고·배당까지 확인하려면 긴 화면을 계속 스크롤해야 합니다.

## 재설계 방향

### 안 1 — 검색·사업군 비교를 앞세운 조사 화면 **(추천)**

- **첫 화면, 위→아래:** 간결한 제목과 기준일·주간 갱신 표시 → 종목명·코드 검색 → 사업군 선택 및 사업군별 비교 대상 수 → 관심 종목 → 검색 결과 또는 선택 사업군의 비교 표 → 제외·경고와 자료 결측 안내.
- **종목 상세:** 종목명·시장·사업군·관심 표시 → 사업군 내 위치 5구간과 “검증된 신호 아님” → PER·PBR·ROE·모멘텀 등 지표별 종목값/사업군 중앙값/백분위 → ‘진짜인가’ 회계 점검 4개 → 경고·제외 이유·결측 이유 → 배당 및 사업 설명.
- **휴대폰:** 검색과 사업군 선택을 상단에 두고, 결과는 비교할 핵심 값 중심의 카드로 표시합니다. 상세는 핵심 요약과 지표·회계 점검·배당 섹션으로 나눠 긴 시트에서 필요한 항목을 찾기 쉽게 합니다.
- **장점:** 앱의 정해진 목적과 가장 잘 맞고, PC와 휴대폰에서 같은 탐색 순서를 유지하기 쉽습니다.  
  **단점:** 종목을 고르기 전의 시장 전체 요약은 줄어듭니다.

### 안 2 — 사업군 먼저 고르는 비교 워크벤치

- **첫 화면, 위→아래:** 기준일·데이터 상태 → 사업군 목록(비교 가능 수와 신뢰도 포함) → 선택한 사업군의 중앙값 요약 → 해당 사업군 종목 비교 표 → 관심 종목.
- **종목 상세:** 공통 상세 구성에 더해, 선택 사업군 안에서 종목의 위치와 중앙값 대비 차이를 우선 배치합니다.
- **휴대폰:** 사업군을 먼저 고른 뒤 종목 카드나 가로 스크롤 비교표로 살핍니다. 지표가 많으면 핵심 지표를 먼저 보여주고 나머지는 확장합니다.
- **장점:** “같은 업종 안에서 비교”를 가장 분명하게 드러냅니다.  
  **단점:** 아직 특정 종목을 찾으려는 사용자는 사업군 선택을 한 단계 거쳐야 합니다.

### 안 3 — 종목 검색 중심의 간결한 목록

- **첫 화면, 위→아래:** 제목·기준일·검증 안내 → 큰 검색창 → 검색 결과 목록 → 사업군과 배당 탐색 링크 → 관심 종목.
- **종목 상세:** 종목 요약 → 사업군 위치 → 지표 비교 → 회계 점검·경고·제외 사유 → 배당·사업 설명.
- **휴대폰:** 검색 후 한 종목씩 상세에서 조사합니다. 목록 카드는 이름·사업군·핵심 지표만 담고, 나머지는 상세로 보냅니다.
- **장점:** 원하는 종목을 빠르게 찾기 쉽고, 휴대폰 화면이 단순합니다.  
  **단점:** 여러 종목을 한 번에 비교하거나 사업군을 둘러보는 기능이 약해질 수 있습니다.

**추천은 안 1입니다.** 사용자의 종목 검색과 사업군 비교를 모두 첫 화면에서 시작할 수 있고, 순위 중심 화면에서 조사 도구 중심으로 전환하는 방향에도 맞습니다. 점수는 목록의 주된 정렬 기준이나 매수 후보처럼 내세우기보다, 상세에서 사업군 내 위치와 근거 지표를 설명하는 보조 정보로 두는 구성이 적절합니다.

레퍼런스의 기능 설명은 서비스 공식 페이지와 안내를 확인해 작성했습니다. 개별 서비스의 실제 배치·무료 제공 범위는 계정·화면 변경에 따라 달라질 수 있습니다.
