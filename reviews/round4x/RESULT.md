## 합격 기준 (D-27 · DESIGN 7.8)

**데이터 게이트** — DESIGN 7.2 인정 조건 + 생존자 편향 점검(재무 미매핑 비율 상장폐지 vs 생존) 미충족이면 성과와 관계없이 "탐색적 분석".

**성과 게이트** (기준 비용, 검증 구간에서 모두 충족):
1. 상위 20 포트폴리오 연환산 초과수익 **≥ 3%p** (유니버스 동일비중 대비), 그리고 보유 종목의 소속 사업군 평균 대비 초과수익 > 0
2. 5분위(종합점수, 3개월 사업군 대비 수익): 최상위 − 최하위 > 0, **인접 역전 ≤ 1회**
3. IC(종합점수 vs 다음 3개월 사업군 대비 수익 순위상관) 평균 > 0, **IR ≥ 0.3** (t값은 공개만)
4. 최상위 5분위의 사업군 대비 승률 > 50%, 리밸런싱 단위 95% 신뢰구간 하한 > 50% (아니면 '미판정')
5. 안정성: 달력 연도 절반 이상에서 유니버스 대비 초과수익 > 0, 누적 기여 상위 3종목 제외해도 초과수익 > 0

**표시 규칙** (탈락은 아님):
- MDD가 유니버스 동일비중보다 5%p 넘게 나쁨 → "사용자 재검토"
- 보수 비용에서 초과수익 ≤ 0 → "비용 민감", '통과' 표현 금지

**판정**
- 개발 구간: 1~4의 방향(부호) 진단. 실패 시 검증 구간을 열지 않고 7.5 비교 실험을 사용자에게 숫자로 제시, 버전 변경은 사용자 결정
- 개발 통과 + 검증 통과 (+ 데이터 게이트) → 화면 표시 "과거 검증 기준 통과 (기간·비용 조건 명시)". 미래 성과 보장 표현 금지
- 개발 통과 + 검증 실패 → 실패 기록, '가설' 표시 유지. 검증 구간 보고 수정하면 새 버전, 그 구간은 더는 독립 검증이 아님
- 문턱 값은 경제적 최소 크기이며 통계 법칙이 아님 — 민감도·신뢰구간 함께 공개
