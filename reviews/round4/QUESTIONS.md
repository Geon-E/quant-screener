## 공유 사항 (질문 아님 — 사용자 결정 또는 불가피한 변경)

1. **D-25 (사용자 결정)**: 현재 시점 스크리너 화면을 먼저 만들고 과거 성과 검증은 병행한다. 화면에는 "점수는 가설·성과 미검증"을 상시 표시한다. D-23 작업 순서가 바뀐다.
2. **D-22 방식 변경 (사용자 승인)**: 사용자·GPT 모두 DART 원문을 열 수 없어 사람 확인이 불가능했다. 대신 계정 선택 규칙을 거치지 않은 값(DART 주요계정 API, 사업보고서 배당 항목)과 자동 대조했다. 결과는 368건 중 정확 일치 365건, 회사 기재 방식으로 설명되는 3건, 우리 오류 0건.

의견이 있으면 Q7에 적는다.

## Q1. 코스피 관리종목의 과거 이력 (D-15)

실험 결과 (코스닥 KRX 소속부를 정답지로, 278거래일):
- DART 시장조치 공시: 관리종목 '지정' 공시 자체가 없음. 누락률 84%, 오탐률 81%
- KIND 현재 목록: 정답지 대비 누락 0, 초과 5. 다만 **현재 목록만** 제공(과거 이력 없음). robots.txt는 방화벽 차단 페이지가 응답되어 확인 불가 → 현재 사용 중단
- 코스피 관리종목은 현재 약 45종목(코스피의 약 5%)

| 선택안 | 내용 |
|---|---|
| A | 앞으로 매일 현재 목록을 쌓고, 과거 구간 백테스트는 "코스피 관리종목 필터 미적용"으로 표시 |
| B | 관리종목 지정 요건(자본잠식, 감사의견, 매출액 미달 등)을 재무·공시로 직접 판정. 코스닥 정답지로 정확도를 측정해 일정 수준 이상일 때만 사용 |
| C | 관리종목 필터를 빼고 재무 건전성 필터(자본잠식·적자·F-스코어)로 대체 |
| D | A와 B 병행 (현재는 목록, 과거는 요건 판정) |

## Q2. 상장폐지 소스의 역할 (D-19)

D-19 합의: KRX 시세(마지막 관측) / KIND(공식 폐지일·사유) / FinanceDataReader(차이 탐지).
실험 결과:
- KRX 상장폐지종목 현황(MDCSTAT23801)을 FinanceDataReader가 GitHub에 공개 캐시해 둔 파일: 2015년~ 연 114~219건. 백필 기간에 시세가 끊긴 106종목 **전부** 1영업일 안에 폐지일 일치(명절 1건 포함), 폐지 사유 포함
- KIND: robots.txt 확인 불가로 사용 중단
- DART 시장조치 공시: 106종목 중 0건 설명

| 선택안 | 내용 |
|---|---|
| A | 공식 폐지일·사유는 KRX 상장폐지종목 현황(공개 캐시), KRX 시세 마지막 관측일로 교차 확인 |
| B | 원래 합의 유지 — KIND를 쓸 수 있을 때까지 상장폐지 처리 보류 |
| C | A로 시작하되, 공개 캐시가 끊기거나 불일치가 생기면 KRX 시세만으로 처리하고 플래그 |

## Q3. 확인되지 않은 기업행위의 백테스트 수익률 처리

수정주가는 KRX 기준가 조정계수로 만든다. 주식수 역수 관계(분할·병합)나 DART 공시로 확인되지 않는 기준가 변경이 있다. 예: 선도전기 2026-04-29, 주식수 변화 없이 기준가 3,000원→5,000원 재설정. 현재 모멘텀은 무효 처리한다.

| 선택안 | 내용 |
|---|---|
| A | 수익률 계산에서도 보정하지 않고(실제 가격 그대로) 해당 종목에 플래그 |
| B | 미확인 사건이 있는 종목은 그 보유 기간을 백테스트에서 제외 |
| C | 조정계수를 그대로 적용 |

## Q4. D-16 문구와 구현의 차이
