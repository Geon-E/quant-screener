# 4차 협의 안건 (누적)

> 질문지(QUESTIONS.md)는 안건이 모이면 [협의 방식](../../docs/DEBATE_PROTOCOL.md)대로 중립 문장으로 작성한다.

| # | 안건 | 배경 | 현재 구현 |
|---|---|---|---|
| 1 | **D-22 방식 변경 확인** — 사람 확인 → 자동 대조 | 사용자·GPT 모두 DART 원문 열람 불가 (GPT 62행 전부 미확인). 사용자 승인 후 변경 | DART 주요계정 API + 사업보고서 배당 항목과 자동 대조, 368건 중 우리 오류 0 ([결과](../../docs/PHASE1_STATUS.md#원천값-자동-대조-d-22-변경--2026-10-25)) |
| 2 | 자동 대조의 한계를 2단계에서 어떻게 보완할지 | 같은 공시 원천이라 공시 자체 오류는 못 잡음. 배당 항목은 회사마다 기재 방식이 다름(전체 순이익 기재 2건, 단위 오기 1건) | 2단계 전 종목에도 같은 대조를 돌려 불일치율을 보고하는 안 |
| 3 | **D-16 문구와 구현 차이** | 합의 문구 "공시 기반 보정" | 거래소 공식 기준가를 주 소스, 공시는 확인용 |
| 4 | 미확인 기업행위의 백테스트 수익률 처리 | 선도전기: 주식수 변화 없는 기준가 재설정 | 모멘텀은 무효. 수익률은 보정 안 함 + 플래그 (기본값 제안) |
| 5 | **D-19 역할 조정** — 공식 폐지일·사유를 KIND 대신 KRX 상장폐지종목 현황(FDR 공개 캐시)으로 | KIND는 robots.txt 확인 불가. KRX 현황은 백필 106종목 전부 날짜 일치, 2015~ | 실험만 완료, 파이프라인 미반영 |
| 6 | **D-15 코스피 관리종목 과거 이력** — 소스 없음 | DART엔 지정 공시 없음, KIND는 현재 목록뿐. 코스피 관리종목은 현재 45종목(약 5%) | 선택지: (a) 앞으로 매일 현재 목록을 쌓고 과거 구간은 '미적용' 표시 (b) 관리종목 요건(자본잠식·감사의견·매출 미달 등)을 재무로 직접 판정, 코스닥 정답지로 정확도 측정 (c) 관리종목 필터 대신 품질 필터로 대체 |
