# 5차 추가 안건 — 미사용 구간(2016~2018) 사전 등록안 검토 요청

> 배경: 5차 RESULT는 "첫 가설은 '하위 20% 회피'(H1) 하나만"이었다. 이후 원인 진단(EXPERIMENTS #6, diagnostic_only)에서
> **상위 5분위 전체(약 110~130종목) 동일비중이 두 구간 모두 순위 대상 전체 동일비중보다 나았다**(개발 +1.3%p, 검증 +3.1%p, 비용·한도 없음).
> 사용자가 이 관찰을 두 번째 가설(H2)로 추가하기로 결정했다(2026-11-12). 이 문서는 **미사용 구간을 열기 전에** 판정 규칙을 고정하기 위한 검토 요청이다.
> GPT에게: 아래 등록안의 허점(사후 선택 흔적, 다중 비교, 기준 완화 여부, 계산 정의 모호함)만 지적해 달라. 결과 예상은 하지 않는다.

## 미사용 구간
- 2016-05-01 ~ 2018-03-31 (분기 교체 약 7회: 2016-05·08·11, 2017-04·05·08·11)
- 시작점 근거: 시세 2015-01부터 수집(12-1 모멘텀 13개월), 재무 2015년 사업보고서 공시 후. **수익률을 보기 전에** 커버리지(순위 대상 수, 재무·시세 결측률)만 먼저 확인해 시작 분기를 확정한다. 순위 대상이 300개 미만인 분기는 제외.
- 전략: v1 그대로(frozen). 점수·유니버스·필터 변경 없음.

## 가설과 판정 (두 가설이므로 신뢰구간 배수를 1.96 → 2.24로 높임)

**H1 하위 20% 회피**: 매 분기 순위 대상의 v1 점수 최하위 5분위 동일비중 수익률 − 각 종목이 속한 사업군 평균 수익률의 평균(다음 분기, 비용 없음).
- 통과: 분기 평균 < 0 **그리고** 7분기 중 5분기 이상 음수 **그리고** 평균 + 2.24×표준오차 < 0
- 미판정: 평균 < 0 이지만 위 둘 중 하나 미달
- 실패: 평균 ≥ 0

**H2 상위 20% 넓게 보유**: 매 분기 v1 점수 최상위 5분위 전체를 동일비중으로 보유, 사업군 한도 없음. 비용은 분기 회전율 × 0.6%(매도세·수수료·스프레드 왕복 근사) 차감. 비교는 순위 대상 전체 동일비중(비용 없음).
- 통과(D-27 그대로): 연환산 초과 ≥ +3%p **그리고** 7분기 중 5분기 이상 초과 **그리고** 분기 초과 평균 − 2.24×표준오차 > 0
- 미판정: 연환산 초과 > 0 이지만 위 기준 미달
- 실패: 연환산 초과 ≤ 0

## 공통
- 결과는 이 문서 커밋 이후에만 계산한다. 계산 후 규칙을 바꾸면 이 구간은 개발 자료로 강등.
- 어느 쪽이 통과해도 **실시간 기록(D-32)에서 다시 확인**하기 전에는 화면에서 매매 신호로 쓰지 않는다.
- 2016~2017은 현재 업종 분류·관리종목 이력 한계가 개발·검증 구간보다 클 수 있다 → 결과에 한계로 명시.
