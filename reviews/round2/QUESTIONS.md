## Q2. 비교 사업군(업종 그룹) 구성 방식

문제: KSIC 기준으로 묶으면 종목이 3~5개뿐인 업종이 생긴다. 이 경우 업종 내 백분위가 불안정하다.

| 선택안 | 내용 |
|---|---|
| A | 실행할 때마다 종목 수를 확인해 기준(예: 10개) 미만이면 상위 분류로 자동 병합 |
| B | 사람이 미리 검토해 묶은 고정 사업군 표를 버전으로 관리. 소표본 사업군은 점수 신뢰도 "낮음" 표시 |
| C | KSIC 원분류를 그대로 쓰고, 소표본 사업군은 신뢰도만 표시 |
| D | 업종 상대 점수와 전체 시장 상대 점수를 표본 크기에 따라 가중 혼합 (예: 축소추정) |

## Q3. 계산 검증과 백테스트의 순서

| 선택안 | 내용 |

## Q6. 최초 공시 값 복원(XBRL) 적용 범위

0단계 실측 결과는 다음과 같다.
- 재무 API는 최신 정정본을 반환한다.
- 접수번호별 원본 XBRL로 최초본 복원이 가능하다.

| 선택안 | 내용 |
|---|---|
| A | 1단계에서는 정정공시가 있는 기업만 XBRL로 최초본 확보, 백테스트 단계에서 전 기간 확대 |
| B | 처음부터 모든 공시를 XBRL로 수집해 단일 경로로 통일 (재무 API는 보조) |
| C | 실전 추적(앞으로 수집분)만 최초본 보장, 과거 백테스트는 최신 정정본 사용 + 한계 표기 |

## Q7. 코스피 관리종목 식별

0단계 실측 결과, KRX 종목기본정보에 코스닥 관리종목은 표시되지만 코스피는 표시되지 않는다.

| 선택안 | 내용 |
|---|---|
| A | KIND 관리종목 현황 페이지 수집 |
| B | DART 공시(관리종목 지정·해제)로 식별 |
| C | 코스피는 관리종목 필터 생략, 다른 위험 필터로 보완 |

## Q8. 수정주가 계산

KRX는 원 종가만 제공한다.

| 선택안 | 내용 |
|---|---|
| A | 상장주식수 변화 + 가격 불연속으로 분할·병합 자동 감지 |
| B | DART 주요사항보고(분할·병합·증자 결정) 공시로 보정 |
| C | 비공식 소스(예: FinanceDataReader)의 수정주가 사용 |
| D | A로 감지 + B로 확인, C는 교차검증용 |

## Q9. 1단계 착수 범위

| 선택안 | 내용 |
|---|---|
| A | 표본 20~30개사로 수집→정규화→점수 전 과정을 먼저 완성·검증한 뒤 전 종목으로 확대 |
| B | 처음부터 전 종목 수집 파이프라인을 만들고, 계산 검증은 표본으로 |
| C | 시세(KRX)만 전 종목, 재무(DART)는 표본부터 |

추가로, **1단계 완료 기준**에 넣어야 할 항목이 있으면 제시한다.

| 선택안 | 내용 |
|---|---|
