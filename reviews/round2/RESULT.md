## 1단계 필수 점검·완료 기준 (Q1·Q9 통합)

### 1단계 안에서 해결할 검증 실험
- [ ] 코스피 관리종목: KIND vs DART 표본 비교 (Q7)
- [ ] KIND 상장폐지현황 자동 수집 가능성·과거 커버리지 (Q10)
- [ ] 최초 적재 호출량 산정표 + 시험 적재로 실제 한도·소요일 확정
- [ ] 감가상각비 계정 매핑 커버리지 (EBITDA/EV 실효성)
- [ ] 최초 검증 가능일 산정: 재무 TTM 4개 분기 + 12-1 모멘텀 가격 + 기업행위 보정 중 가장 취약한 데이터 기준
- [ ] 과거 업종 분류: 현재 분류 사용의 한계 기록, 사업군 변경 민감도 확인 방법 정의

### 1단계 완료 기준 (게이트)
1. 표본 20~30개사의 핵심 계정·파생지표가 독립 수작업 계산과 일치 (허용오차·실패 기준 명시)
   - 표본에는 적자, 결산월이 12월이 아닌 기업, 정정공시, 비표준 계정, 지배·비지배 차이가 큰 기업, 상장폐지 기업, 기업행위 사례를 포함한다.
2. 누적/3개월 금액, 4분기 역산, TTM, 연결/별도, 지배주주 항목의 자동 테스트 통과
3. 정정공시·공시 시점·수집 지연을 포함한 시점 재현 테스트 통과
4. 기업행위 조정·상장폐지 처리의 테스트 사례와 미지원 범위 문서화
5. API 실패·한도 초과·빈 응답·중복 응답 시 마지막 정상본 보존 + 상태 표시
6. 필수 데이터 항목별 커버리지·결측률 보고, 미충족 항목은 순위 산정에서 명시적 제외
7. **결정성**: 데이터·설정·코드 버전을 고정한 상태에서 같은 L0 입력으로 L1·L2 결과의 해시가 일치
8. **보안**: 결과물·로그에 키 문자열이 없음을 자동 검사
9. **호출량 리포트**: 실행별 API 호출 수 기록
10. **재개 가능성**: 중단 후 재실행 시 중복·누락 없음
